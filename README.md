# Book (GitHub Pages)

Це простий прототип «бібліотеки + читач», який працює як статичний сайт (наприклад, GitHub Pages).

## Два варіанти каталогу (manual / auto)

У тебе є **2 варіанти**, як формується `books/index.json`:

### Варіант A — вручну (без скрипта)
Ти сам редагуєш файл:
- `books/index.json`

Плюси: найпростіше, без додаткових інструментів.  
Мінуси: легко помилитися/забути додати нову книгу.

### Варіант B — автогенерація (локальним Python-скриптом)
Ти додаєш нову книгу як папку `books/<id>/...`, а потім запускаєш скрипт локально, який сам збирає `books/index.json`.

⚠️ Важливо: **на GitHub Pages Python не запускається автоматично**. Скрипт запускається:
- вручну на комп’ютері перед комітом/деплоєм, або
- у GitHub Actions (якщо захочеш зробити CI).

## Структура папок книги

Кожна книга — це папка:

```
books/
  index.json
  invisible-sandwich/
    book.json
    cover.jpg
    translate_uk.txt   (опціонально, тільки для режиму «Читати»)
    translate_ru.txt   (опціонально)
    translations/
      pl.txt           (опціонально)
```

### `book.json` (мінімально)
Обовʼязкові поля:
- `id`
- `title_en` / `title_ua`
- `level`
- `durationMin`
- `cover` (можна шлях відносно книги)
- `description`
- `text` — масив рядків (кожен рядок = один рядок/абзац)

Приклад:
```json
{
  "id": "invisible-sandwich",
  "title_en": "The Invisible Sandwich",
  "title_ua": "Невидимий сендвіч",
  "level": "A1 English Learners",
  "durationMin": 12,
  "cover": "cover.jpg",
  "description": "…",
  "text": ["Chapter 1: ...", "Tim is hungry...", ""]
}
```

## Режими

### 1) «Слухати»
- Текст з підкресленням слів + переклад **слова** по кліку/тапу.
- Підсвітка: «активне слово».

### 2) «Читати»
- Показує **рядок оригіналу + рядок перекладу** (переклад можна вимкнути в налаштуваннях).
- Немає перекладу по тапу на слово.
- Підсвітка синхронізована з озвучкою **по рядках** («активне речення»).
- Заголовки `Chapter N:` автоматично жирні.

## Переклади для «Читати»: файл або API

Тільки для режиму «Читати» є 2 джерела перекладу:

1) **Локальний файл перекладу** (пріоритет №1)  
Поклади файл у папку книги:
- `books/<id>/translate_uk.txt`
- або `books/<id>/translations/uk.txt`
- або `books/<id>/translation_uk.txt`

Формат: **построчно**, рядок №N відповідає рядку №N з `text`. Порожній рядок = порожній рядок.

2) **API (LibreTranslate)** (fallback)  
Якщо локального файлу немає — переклад береться через API.
